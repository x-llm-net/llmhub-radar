# Marketplace Console Roadmap

## 已确认的权限规则

- 管理员不受服务商数量限制，可以创建服务商并指定或转移归属。
- 普通用户最多创建 1 个服务商草稿，不能认领平台已收录的服务商。
- 认证用户最多管理 3 个服务商，可以创建服务商，也可以对平台托管的服务商提交认领申请；账号认证只证明申请人身份，服务商归属仍需管理员审核。
- Pro 计划最多管理 10 个服务商，首版只预留权益定义，不实现订阅和购买。
- 已创建、已认领的服务商和待审核认领申请均占用额度；申请被驳回后释放额度，审核通过后由待审核额度转为已归属额度，不重复计算。
- 同一服务商允许多人提交认领申请；管理员批准其中一份后转移归属，并自动驳回该服务商的其他待审核申请。
- 认领争议由管理员人工处理；管理员可以锁定服务商并变更归属。
- 管理员变更归属时写入审计日志，保留操作者、变更前后归属和时间；消息通知随认领流程后续补充。
- 归属转移保留公开资料、分组、探测目标、历史观测和排名；平台托管服务商被认领时，正在使用的平台代理探测密钥最多继续运行 24 小时，但不会向认领者展示。
- 认领者应在交接期内使用自己的 API Key 替换原凭据；替换沿用原凭据和探测目标，因此不会切断历史数据。
- 交接期结束仍未替换时，系统清除平台代理密钥并暂停对应探测，页面显示等待配置，不记为失败或服务不可用。
- 用户之间转移归属或转回平台托管时，不提供 24 小时密钥交接，原管理者的 API Key 立即清除并暂停探测。
- 认证或付费不能改变探测规则、检测分和自然排名。
- 资质认证属于账号主体，不绑定具体网站；个人认证采集姓名、身份证号和手机号，企业认证采集企业名称、统一社会信用代码、法人姓名和法人身份证号。
- 认证资料由管理员人工审核；待审核的证件号和手机号加密保存，审核完成后删除完整密文，仅保留脱敏值和不可逆校验值。网站归属证明在服务商认领申请中单独提交并由管理员核验。
- 已通过个人认证的账号可以免费升级为企业认证；审核期间和驳回后保留原个人认证及服务商额度，企业审核通过后以最新企业认证作为当前主体。

## 控制台导航

### 工作台

- 概览：现有页面，已启用。
- 我的服务商：现有 Radar 列表，已启用。
- 数据与排名：已启用，按账号下服务商汇总模型自然排名、7 日可用率、覆盖率、样本和未达门槛原因。
- 通知中心：现有订阅通知页面，已启用。

### 账号与权益

- 认证与权益：已启用，支持个人/企业认证申请、管理员审核、认证状态和 3 个服务商额度；Pro 仅展示规划权益。
- 订单记录：规划中，待支付方案确认后实现。
- 账号设置：现有账号页面，已启用。

### 支持

- 联系我们：QQ、微信和商务合作邮箱，已启用。

## 页面实施顺序

1. 我的服务商：先确定列表信息、额度展示、创建入口和认领入口。
2. 服务商归属：已实现普通用户与认证用户额度、认领申请与管理员审核、管理员直接指定及转移归属，以及审核通过后的 24 小时探测密钥交接。
3. 认证与权益：已实现个人/企业认证状态、管理员审核、敏感资料保护和普通、认证、Pro 权益对比；支付暂不接入，由管理员线下确认 99 元永久认证费用。
4. 服务商工作台：整理服务概览、公开资料、探测与模型、排名表现、状态页与嵌入、公告与订阅。
5. 数据与排名：已实现账号下各服务商的具体模型名次、7 日趋势、覆盖样本和观测门槛筛选。
6. 订单记录：接入 99 元认证订单后启用。
7. Pro：确认套餐价格和权益后单独实施，不影响自然排名标准。

每个规划中页面在方案确认和功能完成前保持禁用，不创建无功能的空页面。
