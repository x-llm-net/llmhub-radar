# 渠道商通知

## 功能范围

管理员可以在“系统设置 -> 运维 -> 渠道商通知”配置渠道商申请和审核结果通知：

- 站内通知：所有管理员共享渠道商申请、审核结果记录；已读状态保存在当前浏览器中。
- 浏览器通知：管理员打开后台并授权浏览器通知后，页面轮询到新事件时提示。它只在后台页面打开时有效，不是离线 Push。
- 邮件：复用现有 SMTP 设置，可以配置多个收件地址，一次发送给全部地址。
- 企业微信：可以配置多个机器人 Webhook，每个目标可单独启用或停用。

系统支持分别开关总通知、新申请通知和审核完成通知。邮件地址和 Webhook 目标会在后端校验、去重并限制数量；Webhook 请求沿用现有 SSRF 防护和 Worker 代理路径，企业微信返回的业务 `errcode` 非 0 会被视为失败并记录日志。

## 权限与接口

- 通知列表：管理员可读。
- 通知设置读取、保存和测试发送：仅 Root 管理员可用。
- 保存设置不会把 Webhook URL 混入通用公开选项接口。

后端接口：

```text
GET  /api/hub/admin/notifications
GET  /api/hub/admin/notifications/settings
PUT  /api/hub/admin/notifications/settings
POST /api/hub/admin/notifications/settings/test
```

## 触发时机

- 渠道商申请成功创建后触发一次“新申请”通知。
- 管理员成功修改渠道商审核状态后触发一次“审核完成”通知。
- 仅打开渠道商中心、读取申请详情或刷新页面不会触发通知。

站内记录先写入数据库，邮件和 Webhook 在后台异步发送；每个发送目标失败后最多重试一次。发送失败不会回滚申请或审核状态，服务日志会记录失败目标，管理员仍可从站内通知查看事件。

测试发送只验证当前配置的外部目标，不新增站内通知记录，也不会伪造渠道商申请或审核事件。
